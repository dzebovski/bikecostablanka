## 1. Бізнес-цілі

- [ ] Зафіксувати головну мету: отримувати запити та бронювання будинку в Ондарі.
- [ ] Визначити пріоритет: тривале зимове проживання на 1–3 місяці.
- [ ] Визначити другорядні цілі: коротші велоподорожі, сімейний та активний відпочинок.
- [ ] Вирішити, який термін проживання є мінімальним і оптимальним.
- [ ] Визначити сезонність, доступні місяці й пікові періоди.
- [ ] Сформувати місячні, тижневі та сезонні тарифи.
- [ ] Визначити умови депозиту, скасування, комунальних платежів і прибирання.
- [ ] Сформулювати одну головну обіцянку сайту.

Робоче позиціювання:

> BikeCostaBlanca допомагає самостійно відкрити велосипедну й повсякденну Коста-Бланку, використовуючи комфортний будинок в Ондарі як базу для відпустки або тривалого зимового проживання.

### Велосипедисти з партнерами або сім'ями

- [ ] Пари, де катається лише одна людина.
- [ ] Сім'ї з дітьми.
- [ ] Групи зі змішаними інтересами.
- [ ] Дві або більше пар, які подорожують разом.

Їм важливі:

- пляжі;

- можливість користуватися автомобілем;
- комфорт будинку для всіх, а не тільки для спортсменів.

Основне повідомлення:

- [ ] Пенсіонери й напівпенсіонери.
- [ ] Remote workers.
- [ ] Пари, які хочуть провести зиму в теплому кліматі.
- [ ] Люди, що розглядають переїзд або зимування в Іспанії.
- [ ] Активні гості, для яких велосипед — лише одна з частин способу життя.

Їм важливі:

- велосипеди не здаються в оренду;
